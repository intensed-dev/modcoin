# ModCoin

**MOD** is a fictional cryptocurrency market simulation.

This project is a static GitHub Pages dashboard that generates synthetic price history from deterministic simulation factors. It is not a real cryptocurrency, investment product, or financial data source.

## Features

- Simulated MOD/USD price
- Interactive 7D, 30D, 90D, 1Y and ALL chart ranges
- Market cap, volume, ATH and ATL
- Daily simulated OHLC history
- Fictional time-of-day, creator-activity and market-noise drivers
- Daily GitHub Actions data generation
- No database or build system required

## GitHub Pages

The repository contains a Pages deployment workflow in `.github/workflows/pages.yml`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if GitHub has not selected it automatically.

## Disclaimer

MOD has no monetary value. All market data shown by this project is fictional and generated for demonstration purposes.
